1. デッキログ貼り付けツール

下のリンクをブックマークバーにドラッグ&ドロップして登録してください。 クリックでは登録できません(実行されてしまいます)。

デッキログ貼り付けツール

使い方

  1. 上のリンクをブラウザのブックマークバーにドラッグして登録する。
  2. デッキログ(decklog.bushiroad.com)のデッキ詳細ページ(例: https://decklog.bushiroad.com/view/XXXXX)を開く。
  3. 登録したブックマークレットをクリックすると、画面右上に小さなパネルが表示される。
  4. 「デッキ名をコピー」→ 管理ツールのデッキタイトル欄に貼り付け。
  5. 「カードリストをコピー」→ 管理ツールの各プレイヤー枠にある一括貼り付け欄に貼り付けて「解析してカード表に反映」を押す。

※ カードリストにはクライマックスカードも含む全カードが入ります。クライマックス構成(袋/扉/風など)は 従来通り管理ツール側で手動選択してください。

ソースの可読版は admin/bookmarklet/decklog-copy.js にあります。修正する場合はそちらを直し、 このページの javascript: リンクにも同じ内容を反映してください。

2. 公式カードリスト貼り付けツール

下のリンクをブックマークバーにドラッグ&ドロップして登録してください。

カードリスト貼り付けツール

使い方

  1. 上のリンクをブラウザのブックマークバーにドラッグして登録する。
  2. 公式カードリスト(ws-tcg.com/cardlist/)で検索・絞り込みをして、登録したいカード一覧を表示する。
  3. 登録したブックマークレットをクリックすると、画面右上に小さなパネルが表示され、その時点で表示されている一覧の全カードが自動でリストに追加される(モーダルを開く必要はない)。
  4. 絞り込み条件を変えたりページを送ったりして一覧の中身が変わった場合も自動で追従して追記される(反映されない場合は「再読み込み」を押す)。
  5. 「全てコピー」→ カードマスタ管理タブの一括登録欄に貼り付けて「解析して登録」を押す。

※ クライマックスカードは、公式ページに「クライマックス種別(袋/扉/風など)」の情報が無いため、 該当欄が空欄で出力されます。貼り付け後、コピーしたテキスト上でクライマックスの行だけ手動で 種別を追記してから「解析して登録」を押してください。

ソースの可読版は admin/bookmarklet/cardlist-copy.js にあります。修正する場合はそちらを直し、 このページの javascript: リンクにも同じ内容を反映してください。
